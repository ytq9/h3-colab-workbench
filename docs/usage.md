# ComfyUI 使用

## 从一个五秒镜头开始

工作流是由节点和连线组成的一次生成配方。打开内置的省额度预设，主要调整：

1. **提示词节点**：主体、动作、镜头运动、环境、声音。先写一个明确的镜头。
2. **Resolution Selector**：画面方向和像素量。预设使用 16:9、0.2 MP、32 对齐。
3. **时长**：预设 5 秒。模型按帧数网格对齐，输出约 5.17 秒是正常现象。
4. **Turbo / 采样步数**：省额度预设开启 Turbo，使用 8 步；关闭 Turbo 后使用普通步数。
5. **SaveVideo**：保存并显示结果，文件自动按任务编号隔离，避免重名覆盖。

图生预设先在“上传自己的图片”节点选择图片，再写动作。输入图应接近目标宽高比；当前 H3 首帧处理可能拉伸到目标画布。

画布空白处拖动可以移动视野，滚轮缩放。节点连线规定数据流向；新手先保留预设连线。工作流保存的是生成配方，MP4 是生成结果，两者需要分别保留。

## 1080p

当前节点用 `MP × 1024²` 计算面积：

| 参数 | 横屏 | 竖屏 |
|---|---|---|
| 宽高比 | 16:9 | 9:16 |
| megapixels | 2.0 | 2.0 |
| multiple | 32 | 32 |
| 生成尺寸 | 1920×1088 | 1088×1920 |
| 标准交付尺寸 | 1920×1080 | 1080×1920 |

生成后，横屏上下各裁 4 像素、竖屏左右各裁 4 像素，即得到标准 1080p。这里的尺寸计算已核对；1080p 在 A100 上的显存、速度和额度成本尚未实测，不能按低分辨率样本线性承诺。

优先用小规格验证动作与提示词，再生成正式尺寸。增加分辨率与增加步数会改变成本；每次比较尽量只改一项。

## 额度与批量镜头

Colab 按资源占用计量，准备环境和模型也消耗额度。任务连续排队可以复用一轮 GPU，全部完成后释放。

余额差包含整个时间段的消耗，不是逐条视频账单。低分辨率短片的两次样本不足以估计高清短剧总产能，成片还会受重试次数和可用镜头比例影响。

## 完成、取消与重新连接

- 完成：等待底部显示“GPU 已释放”；继续编辑无需云端 GPU。
- 取消：点击 ComfyUI 中止，程序取消当前远程操作并请求释放。
- 关闭标签后重开：双击启动器，或运行 `h3-workbench start`。
- 授权失效：点击底部“连接 Google”重新授权。
- 释放未确认：点击“重试释放 GPU”，或使用 `h3-workbench release`。仍失败则检查 Colab 管理会话。
