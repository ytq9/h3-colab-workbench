# 验证范围

## 已有实际使用证据

同一固定版本基础上，Mac CPU 画布与 Colab GPU 执行的原型已完成两条图生视频：

| 输出 | 参数 |
|---|---|
| 横屏 | 608×352、24 fps、约 5.17 秒、含音轨 |
| 方形 | 640×640、24 fps、约 5.17 秒、含音轨 |

两个本地 MP4 的大小和 SHA256 与远程结果回执一致。完成后查询过 0 活跃会话、0 CU/小时。本仓库不包含用户视频、请求内容、账号信息或原始回执。

## 正式包的检查

- 使用假 CLI 验证账号/额度门槛、队列复用、素材快照、路径约束、文件校验、释放异常和错误日志保留。
- 验证文件传输只重试一次，不重新申请 GPU 或重跑视频推理。
- 检查配置持久化、虚拟环境 Python 路径、凭据目录隔离。
- 编译独立远程脚本，验证传输保护和会话总时限。
- 校验随包分发的工作流文件与固定上游 SHA256 一致。
- 构建 Python wheel，检查所需资源完整；GitHub CI 执行不需要凭据的测试。

2026-10-21 在 Apple Silicon Mac / Python 3.12.14 上实际从空目录安装 CPU 编辑环境，依赖检查通过；在独立端口启动正式包，验证 CPU 设备、H3 原生节点、完整文生 API 工作流、前端扩展注册及 Host/Origin 拒绝规则。测试配置没有保存 Google 授权，未提交任务，完成后已停止测试后台。

本地可在工作台运行时执行 `.venv/bin/python scripts/smoke_local.py` 重复这些接口检查；它不排队生成。

## v0.1.0 真实 GPU 验证

正式包随后完成一次 A100 高内存请求下的文生最小测试：608×352、Turbo 8 步、24 fps，输出 124 帧、约 5.17 秒的 H.264 视频与 AAC 音轨。输入传送、实际推理、结果取回、大小/SHA256 校验均成功；视频和音轨完整解码通过。

从提交到释放约 316.63 秒，账户余额显示差约 0.27 CU；结束后确认 0 活跃会话、0 CU/小时。该样本包含冷启动准备成本，不代表固定单条计价。脱敏机器可读记录见 [verification-0.1.0.json](verification-0.1.0.json)，用户账号、原始任务和视频文件不随仓库发布。

本地共有 23 项回归测试通过。强制触发的传输重试、异常恢复等分支通过模拟测试；一次真实成功路径不能证明历史间歇故障完全消失。1080p 与长期稳定性仍属于后续实测项目。
