# 故障排查

先运行 `h3-workbench doctor`。它检查本地配置与安装，不申请 GPU，也不打印授权链接或 token。

| 现象 | 处理 |
|---|---|
| 本机网址打不开 | 先运行 `start`；查看 runtime_dir 下的 editor.log；确认端口未被另一程序占用 |
| 提示已有另一份工作台 | 旧进程可能占用同一端口，先结束旧版，或使用独立配置与端口 |
| Google 未连接或账号不符 | 使用配置的邮箱完成本机连接页授权，核对 `account_email` |
| 没有额度或无法分配 A100 | 查询 `usage`，核对 Colab 资源可用性；软件不会自动购买或切换平台 |
| 安装或模型准备慢 | 冷启动包含安装和约 42 GB 模型下载；等待状态更新，避免重复提交 |
| 文件传送失败 | 程序仅重试一次；保持 Mac 联网，检查私有日志中的 upload/download 错误，确认释放后再手动提交 |
| 素材已上传，执行连接失败 | v0.1.1 已修复慢握手竞态；确认实际后台版本，查看私有 logs/transport.log 和对应 exec 日志；生成不会自动重试 |
| 视频下载大小不符 | 不会标为成功；保留 `.part` 以便诊断，不自动重跑生成 |
| GPU 释放未确认 | 点击重试释放；仍不成功则在 Colab 管理会话核对，仅处理本工作台创建的会话 |
| 修改代码后没有变化 | 本机后台需要在队列为空、GPU 释放后停止并重新启动 |

## 已知问题与验证边界

素材上传和生成提交是不同阶段。上传成功后仍可能发生执行连接错误，应根据当前阶段及对应操作日志排查。v0.1.1 修复了慢握手时提前发送命令的问题，并补全连接清理与回复超时处理；已提交的生成不会自动重放。

本机异常退出、睡眠、断网后，远程兜底保护只能在其期限内释放；必要时直接在 Colab 管理会话确认。重启本机不会恢复正在生成的视频任务；会恢复未释放会话的提醒，需先完成释放，再提交新任务。文件写入 Drive 同步目录后，还需等 Drive 客户端同步完成。

1080p、长时间批量运行、A100 40 GB 的所有工作流组合、参考音视频模式和非 Mac 安装尚未完成实测。

## 提交故障

提供版本、阶段、复现步骤、脱敏错误类型及是否已确认释放。不要附加凭据目录、sessions.json、完整 CLI 历史、包含个人素材的任务目录或未检查的日志。
